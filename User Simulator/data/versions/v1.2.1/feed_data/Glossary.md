Glossary:

1. Cohort size = unique user install app
2. Unique users start level = unique user has game start event
3. Unique winners of level = unique user has game over event
4. Start Level (%) = unique users start level/cohort_size
5. Complete Level (%) = unique winners of level/cohort_size
6. Win rate (%) = unique winners of level/ unique users start level
7. During level (%) = Complete Level - start level
8. Between level (%) = (unique users start level (N+1) - winners of level N) / winners of level N
9.Fail rate = 1- (total win level matches)/(total level matches)
10.Churn rate = 1- win rate
