## Methodology

This simulation models player behavior through multiple layers:

1. **Viewport Model** — Board divided into camera-sized regions with overlap. Player pans between regions with configurable timing.
2. **Eye Model** — Effective FOV smaller than camera viewport. Player scans with saccades and fixations, with recheck probability.
3. **Arrow Evaluation** — Head finding time scales with arrow length. Exit path tracing with block recognition. Miss probability for solvable arrows.
4. **Batch Tap** — Player taps multiple solvable arrows before panning, with quick rescans between taps.
5. **Recursive Unblock** — When stuck, player traces blocking chains up to configurable depth.
6. **Fatigue** — Exponential time increase per step (per player type).
7. **Frustration** — Builds on failed scans, decays on successful taps. High frustration causes random panning instead of systematic search.

### Limitations

- Parameters are **estimated**, not calibrated from real playtests.
- No hint system simulation.
- Color confusion penalty not yet implemented (needs color data in level JSON).
- Frustration model is simplified (linear buildup).
